# Restrict UOM Edit (Odoo 17)

Restrict who can create or edit Units of Measure (UoM) and UoM Categories in Odoo 17.

## Key Features
- Restrict UoM editing permissions with a dedicated security group.
- Block create/edit on UoM and UoM Categories for unauthorized users.
- Clear error messages for unauthorized actions.

## How It Works
Users without the `Can Create/Edit UOM` group cannot:
- Create a new UoM.
- Edit an existing UoM.
- Create a new UoM Category.
- Edit an existing UoM Category.

## Configuration
1. Go to **Settings > Users & Companies > Groups**.
2. Add users to the group **Can Create/Edit UOM**.
