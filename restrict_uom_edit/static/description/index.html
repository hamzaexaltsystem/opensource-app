Restrict UOM Edit

Unit of Measure permissions for Odoo 17

This module provides UoM access control in Odoo 17 by restricting the creation and editing of Units of Measure and UoM Categories. Only users in the Can Create/Edit UOM group are allowed to make changes.

Key Features

  • Restrict UoM editing permissions with a dedicated security group.
  • Blocks unauthorized creation and editing of UoM records.
  • Blocks unauthorized creation and editing of UoM Categories.
  • Clear error messages for unauthorized actions.

Screenshot

Configuration

  1. Go to Settings > Users & Companies > Groups.
  2. Add users to the group Can Create/Edit UOM.

Compatibility

Odoo 17 Community and Enterprise
